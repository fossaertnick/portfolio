Project 3: Maui

Het meest recente project en veruit het meest uitgebreide. De applicatie is bedoelt om herinneringen te kunnen opslaan. Deze gebruikt kan hiervoor de specifieke locatie van het apparaat gebruiken, alsook de camera en microfoon. Automatisch wordt er gecheckt voor een funcionerende internetverbinding en indien zo worden de nieuwe aangemaakte objecten opgeslaan in een achterliggende backend ASP .Net Core. Er is ook een SQLite voorzien voor reeds 'gepullde' objecten.
